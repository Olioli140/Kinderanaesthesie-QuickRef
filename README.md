Kinderanästhesie QuickRef iPhone v0.3

Für iPhone optimierte PWA-Version.

Empfohlene Nutzung:
1. Den gesamten Ordner auf einen Webserver / GitHub Pages hochladen.
2. Die URL in Safari auf dem iPhone öffnen.
3. Teilen-Symbol -> "Zum Home-Bildschirm".
4. Danach startet die App nahezu wie eine native iPhone-App.
5. Nach dem ersten Laden funktioniert sie durch den Service Worker auch offline.

Hinweis:
Eine lokal in der Dateien-App gespeicherte HTML-Datei wird unter iOS je nach Version nur als Vorschau geöffnet.
Für volle Funktionalität inkl. JavaScript, Offline-Cache und Home-Screen-Modus sollte die App über HTTPS bereitgestellt werden.

Inhalt:
- Normalwerte
- Atemweg & Material
- Bult-2018-Medikamentenbibliothek
- Flüssigkeit & Blut
- separater aktueller Notfallbereich
- automatische gewichtsbasierte Berechnungen

Sicherheitsstatus:
Referenz-/Simulationshilfe. Vor klinischer Anwendung aktuelle Fachinformation und lokale SOP prüfen.
